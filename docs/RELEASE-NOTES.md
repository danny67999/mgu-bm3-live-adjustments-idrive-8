# MGU Bm3 Live Adjustments for IDrive 8 — 0.1.1

Install through MGU Store by adding `danny67999/mgu-bm3-live-adjustments-idrive-8` and selecting **Releases**.

- **Map switching:** four map cards, automatic ROM identification, active-map display and DME readback after a switch.
- **Burble controls:** read the current setting, select aggression in 0.5 steps, then Apply or turn burbles Off.
- **Vehicle data:** sample reads and live updates for the channels supplied by your vehicle, with units and sample status.
- **iDrive navigation:** touchscreen and rotary-controller support, graphical dashboard and native list controls.
- **Store updates:** renderer dependencies are declared and the internal app ID is preserved for existing installations.

This version introduces the public app name and repository. The source package is built on the head unit using its installed BMW SDK.
